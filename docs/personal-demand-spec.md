这次项目我主要想学习这几个部分：

1. Node.js + Typescript 后端代码的编写，这是我之前没接触过的技术栈，我之前只读过 JS 的教程，但是几乎没有自己上手写过代码。我想的是，你写代码，然后我通过读你写的代码的方式来学习就好了。
2. 前端部分的编写，我不太想学习，可以基本上全权放给你，我提供提示词就好。
3. 关于我想学习的部分，我可能是一个流程是询问你一些问题，然后我会显式告诉你，把回答写入 @docs/learn.md 的**末尾**，方便我查询，
4. 最后客户端的打包我也想学一下，不过最后再说

还有我的一些要求：

1. 所有函数都必须带注释，函数的定义部分要带注释，说明作用和参数，别的地方看情况，大部分时候不太需要，不过你认为很关键的地方也可以加上；
2. @docs/checkbox.md 是项目的进度安排的要求，也就是把项目的实现划分成合理的部分，然后每完成一些部分，就对 checkbox 打勾，标注为完成。
3. 我的一个很常见的 workflow 是告诉你「完成 checkbox.md 里面的相应的内容，并把实现的解释写入 @docs/learn.md」
4. 先实现后端，实现 API 接口，使用 curl 检查，然后再实现前端，最后打包成客户端。所谓的 curl 检查，由于本程序基本上除了改算法之外不会有任何 POST 的 HTTP 请求，所以后端运行的时候应该打日志，记录每一步的操作，方便检查实现的正确性
