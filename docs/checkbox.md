# 项目实现计划

## 1. 项目初始化

- [ ] 初始化 Node.js + TypeScript 后端项目结构。
- [ ] 配置 TypeScript 编译、开发启动命令和基础代码规范。
- [ ] 确定后端目录结构，例如常量、类型、算法、模拟器、API 入口分别放置。
- [ ] 建立基础 README 运行说明，包括安装依赖、启动后端、curl 检查方式。

## 2. 后端核心模型

- [ ] 定义课程固定常量：320 条指令、每页 10 条指令、32 页、4 个内存块。
- [ ] 定义页面、内存块、页表项、访问记录、模拟结果等 TypeScript 类型。
- [ ] 实现指令地址到页号、页内偏移、物理地址的转换逻辑。
- [ ] 为所有函数定义补充注释，说明函数作用和参数。

## 3. 指令访问序列生成

- [ ] 实现符合课程要求的 320 条指令访问序列生成逻辑。
- [ ] 保证访问序列包含顺序执行、前地址跳转、后地址跳转三类来源。
- [ ] 处理边界情况，例如起始指令在地址空间边界附近时仍能生成合法指令。
- [ ] 提供可选随机种子或可复现模式，方便调试和 curl 验证。

## 4. 页面置换算法

- [ ] 实现 FIFO 页面置换算法。
- [ ] 实现 CLOCK 页面置换算法。
- [ ] 实现 LRU 页面置换算法。
- [ ] 抽象统一的算法接口，支持模拟器按算法名称切换。
- [ ] 分别验证三种算法在命中、缺页、内存未满、内存已满时的行为。

## 5. 模拟器流程

- [ ] 实现单步执行逻辑：读取指令、计算页号、判断命中或缺页。
- [ ] 实现缺页处理：记录缺页次数、装入页面、必要时执行页面置换。
- [ ] 实现命中处理：更新算法状态并返回物理地址。
- [ ] 记录每一步执行结果，包括指令号、页号、页内偏移、物理地址、是否缺页、置换信息、内存块快照。
- [ ] 执行完整 320 条指令后计算缺页率。
- [ ] 在后端日志中输出关键过程，便于用 curl 观察正确性。

## 6. 后端 API

- [ ] 提供健康检查接口。
- [ ] 提供获取课程固定配置的接口。
- [ ] 提供生成访问序列的接口。
- [ ] 提供按指定算法运行完整模拟的接口。
- [ ] 提供按指定算法查看单步执行结果或完整执行记录的接口。
- [ ] 使用 curl 检查所有接口返回结构和后端日志。
