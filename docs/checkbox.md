# 项目实现计划

本计划按“每一步都有可运行产物、验证命令、学习笔记输出”的方式推进。

已确定的实现选择：

- 后端 API 使用 Express + TypeScript。
- 自动测试使用 Vitest。
- 第一版按 API 先行推进，但核心算法仍拆成可测试的纯逻辑模块。
- 每完成一个主要阶段，都要把关键实现解释追加写入 `docs/learn.md`。
- 后端阶段同时保留 curl + 日志验证和自动测试。
